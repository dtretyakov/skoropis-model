# skoropis-12 — модель и публикация

Приватный репозиторий: веса, карточка модели и рабочий процесс депозита на Zenodo.
Что за модель, на чём обучена и где отказывает — в [MODEL_CARD.md](MODEL_CARD.md).

```
models/skoropis-12.mlmodel   веса, 15 МБ, kraken 7, сегментация baselines
MODEL_CARD.md                карточка с YAML-шапкой по схеме htrmopo v1
```

## Как опубликовать

Один раз завести секрет: **Settings → Secrets and variables → Actions → New repository
secret**, имя `ZENODO_TOKEN`. Токен берётся на zenodo.org → Applications → Personal
access tokens, права `deposit:write` и `deposit:actions`.

Дальше **Actions → Publish to Zenodo → Run workflow** и заполнить поля:

| поле | что вписать |
|---|---|
| `author_name` | «Фамилия, Имя» — так, как должно стоять в записи |
| `author_orcid` | можно пусто |
| `model` | файл весов; по умолчанию `models/skoropis-12.mlmodel` |
| `doi` | **пусто при первой публикации**; DOI прошлой версии — чтобы выпустить новую |
| `listed` | просить ли включения в сообщество, от этого зависит видимость в `kraken list` |

DOI появится в итоге запуска, на вкладке Summary.

## Новая версия

Положить новые веса, при необходимости поправить карточку — и запустить тот же
workflow, вписав в `doi` идентификатор прошлой версии. Новая версия встанет **рядом**
со старой, ничего не затирая: у каждой свой DOI, а у записи есть concept DOI, всегда
указывающий на свежую.

## Чего здесь нет

**Имени автора.** Оно подставляется в карточку во время публикации из поля запуска и
в репозиторий не возвращается.

**Обучающего набора.** Он стоит на архивных образах, условия доступа к которым
запрещают их воспроизведение. Веса образами не являются и ничего из просмотрщика не
несут.
